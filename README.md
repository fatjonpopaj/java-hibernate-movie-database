\# Java Hibernate Movie Database



Java application for managing movie data using JPA, Hibernate and SQLite.



\## Technologies



\- Java

\- Maven

\- JPA

\- Hibernate

\- SQLite

\- SQL

\- Java Swing



\## Features



\- Manage movies, persons and genres

\- Object-relational mapping with JPA/Hibernate

\- SQLite persistence

\- CRUD operations

\- Maven-based project structure

\- Swing user interface



\## Persistence



The project uses Hibernate as JPA provider and SQLite as database.



The persistence configuration is located in:



`src/main/resources/META-INF/persistence.xml`
